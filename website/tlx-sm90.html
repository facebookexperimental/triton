TLX on sm90 (Hopper)

Supported ops and extension builtins on NVIDIA Hopper.

H100-class GPUs: TMA descriptors, wgmma async MMA, thread-block clusters with distributed shared memory, warp specialization with async_task regions, and mbarrier pipelines. No TMEM, no tcgen05, no CLC — see TLX on sm100 for the Blackwell superset. Tags follow tlx.md.

Supported extension builtins (tlx.*)

The sm100 set minus the Blackwell-only items (TMEM, tcgen05, CLC, TMA gather/scatter, stoch_round, warp_redux, packed PTX).

Notes

•
TMA descriptors need 16-byte-aligned row strides; the mm catalog

entry enforces this via accepts and declines the rest.

•
WGMMA accumulator layouts are Hopper-specific (nv_mma_layout

asserts version 3.0).
